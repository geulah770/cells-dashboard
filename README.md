# שכירות תאים

דשבורד שמראה מי שוכר כל תא, מתי שולם, אילו תאים פנויים ומי צריך לשלם בקרוב. הנתונים נשמרים בגיליון Google Sheets, וכל שינוי בדשבורד נכתב חזרה אליו.

## מבנה

- `index.html`: הדף כולו, בלי שלב בנייה.
- `api/rows.js`: פונקציה ב־Vercel שקוראת וכותבת לגיליון, מוגנת בסיסמה.
- הגיליון: לשונית ״תאים״, שורה לכל תא, עמודות A עד J (ארון, תא, סוג, שם, הערה, חודש, שנה, סוג רישום, תקופה, במקור).

## הגדרה חד־פעמית

1. ב־Google Cloud Console יוצרים פרויקט (או משתמשים בקיים) ומפעילים את Google Sheets API.
2. יוצרים Service Account, ובלשונית Keys מוסיפים מפתח מסוג JSON.
3. בגיליון לוחצים שיתוף ומוסיפים את כתובת ה־`client_email` מתוך הקובץ, עם הרשאת עריכה.
4. ב־Vercel, בפרויקט, תחת Settings ואז Environment Variables, מוסיפים:
   - `GOOGLE_SERVICE_ACCOUNT_JSON`: כל התוכן של קובץ ה־JSON.
   - `DASHBOARD_PASSWORD`: סיסמה לכניסה לדשבורד.
   - `SHEET_ID`: רק אם הגיליון מוחלף. ברירת המחדל היא הגיליון הנוכחי.
5. עושים Redeploy.

בכניסה הראשונה הדף מבקש את הסיסמה ושומר אותה בדפדפן. אם הסיסמה מוחלפת, הדף יבקש אותה שוב.

## הערות

- הכתיבה מוודאת שהשורה בגיליון עדיין מכילה את אותו ארון ואותו מספר תא. אם שורות הוזזו, השמירה נדחית.
- המפתח של חשבון השירות לא נכנס לריפו. הוא נשמר רק במשתני הסביבה של Vercel.
- חישוב מועדי התשלום נעשה בדפדפן לפי הלוח העברי.
